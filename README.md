# SentinEx AI

## AI-Powered Detection & Response Platform for Non-Consensual Intimate Image Sharing

SentinEx AI is a privacy-first platform designed to help victims of non-consensual intimate image sharing detect potential copies or manipulated versions of their private images, organize digital evidence, streamline reporting workflows, and track cases.

## Tech Stack

- Python
- FastAPI
- SQLite
- SQLAlchemy
- Computer Vision
- Image Fingerprinting
- AI / LLM
